1. Getting Started

SmartBot Tg is your central web dashboard for deploying, configuring, and controlling intelligent helper bots directly inside your Telegram groups and project repositories. You do not need programming knowledge or server setups to launch these bots—our visual dashboard simplifies the process into templates you can fill out and deploy with one click.

2. What You Can Do

The dashboard gives you direct control over the following operations:

Customize Bot Templates

Access pre-formatted panels to enter connection details, toggle active modules (like welcome greeting texts, sticker blocks, or chat warnings), and save custom bot profiles.

Launch & Control Runtimes

Start bots instantly with one click. If you need to pause or change parameters, you can click Stop at any time, edit template values, and run them again.

Check Live Telemetry

Track whether your deployed bots are currently active (Running), stopped, or experiencing connection issues directly from your registry dashboard.

Safely Delete Configurations

Remove obsolete configurations. Deleting a template automatically stops the online bot daemon and removes related credentials from storage databases.

Your bot inventory table. Shows bot category icons, unique display names, live running indicators, and control buttons (Start / Stop / Delete).

Templates Tab

Your bot construction desk. Fill out connection inputs, configure active modules, and launch new container threads in real time.

Instances Tab

Live technical monitor. Checks connected server systems, logs core container hashes, and traces status parameters.

4. How to Deploy a Bot with Feature Bricks

SmartBot Tg operates on a modular "Feature Bricks" architecture. Instead of deploying rigid, pre-set bots, you connect a generic bot container and stack functional blocks ("bricks") onto it. This allows you to construct a single bot that moderates groups, chats with PDFs, and reviews GitHub PRs all at once.

6. Best Practices & Security

Adhere to these rules to keep your bot instances safe and running efficiently:

Recommended Actions
  • Use separate Telegram bots for moderation, PDF searches, and GitHub audits. Do not reuse a single token across multiple templates.
  • Toggle off Anjani plugins you do not need to save server memory.
  • Keep document PDFs clean and avoid uploading image-only scanned files without text layers.
  • Regularly stop active bots that are not actively in use to free up system host runtimes.
Things to Avoid
  • Never share your bot tokens with unverified users or post them in public chats.
  • Avoid selecting excessively large vector chunk parameters for PDF chat templates, as this may result in slower reply times.
  • Do not leave error-state bot instances running without stopping and correcting credentials.
  • Do not attempt to review git repositories exceeding the size limit configured on templates.
